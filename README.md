## Hello

I'm a quantitative psychologist, and my work focuses on study design and analytical workflows for evaluating complex systems of behavior---both human and artificial. Special interests include **AI evaluation, trustworthy systems, human-centered machine learning, and applying measurement principles to model behavior**.

Recently, as a project to help with social policy Q&A, I completed a **customizable RAG LLM system** with remote model calls via API. Model response quality is supported by a RAG component to keep answers grounded in source documents, while a psychometric evaluation suite tailored for social policy gauges model competency, reliability, adaptability, recoverability, and conformity. Currently, to learn more about how Bayesian applications can formalize uncertainty tracking in LLM responses, I'm completing a **customizable local LLM system with a Bayesian uncertainty layer** and optional agentic capabilities that can seek additional evidence when needed.
