## Hello

I'm a quantitative psychologist, and my work focuses on study design and analytical workflows for evaluating complex systems of behavior—both human and artificial. Special interests include **AI evaluation, trustworthy systems, model fairness, and applying measurement principles to model behavior**.

Recently, I built a **customizable RAG LLM system** for social policy Q&A, using remote calls via API and retrieval to ground responses in source documents. I also developed a psychometric evaluation suite tailored to social policy, assessing model competency, reliability, adaptability, recoverability, and conformity. Currently, I'm developing a **customizable local LLM system with a Bayesian uncertainty layer** to formalize uncertainty in model responses, with optional agentic capabilities that can seek additional evidence when confidence is insufficient.
